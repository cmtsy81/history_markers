==============================
        GIT ÇALIŞMA REHBERİ
==============================

1️⃣ Başlatma
-----------
git init
(Projeyi git ile takip etmeye başlar)

2️⃣ Durum & Geçmiş
-----------------
git status           (değişiklikleri gör)
git log --oneline --graph   (kısa commit geçmişi)

3️⃣ Değişiklik Kaydetme
----------------------
git add .            (tüm değişiklikleri ekle)
git commit -m "mesaj" (anlık kayıt)

4️⃣ Dallanma (Branch)
--------------------
Yeni dal oluştur ve geç:
git checkout -b ozellik-adi
Mevcut dallar:
git branch
Dal değiştir:
git checkout dal-adi
Ana dala dön:
git checkout main

5️⃣ Dalı Ana Dala Birleştirme
----------------------------
git checkout main
git merge ozellik-adi
Dalı sil:
git branch -d ozellik-adi

6️⃣ Örnek Günlük Akış
---------------------
main
├─> git checkout -b kaydet-butonu
│   │
│   ├─> Kod yaz, test et
│   ├─> git add . 
│   └─> git commit -m "Kaydet butonu eklendi"
│
└─> İş tamamlandıysa:
    git checkout main
    git merge kaydet-butonu

└─> İş başarısız oldu veya başka dalda çözüldüyse:
    git checkout main
    git branch -D kaydet-butonu

7️⃣ Eski Commit / Zaman Yolculuğu
---------------------------------
git checkout <commit_id>   (belirli commit’e git)
git show <commit_id>       (o commit’te ne değişmiş gör)

8️⃣ Özet Tablosu
----------------
Amaç                     Komut
--------------------------------
Yeni özellik geliştirme   git checkout -b ozellik-adi
Durumu kontrol et         git status
Değişiklik kaydet         git add . + git commit -m "..."
Ana dala dön              git checkout main
Özelliği birleştir        git merge ozellik-adi
Dal sil                   git branch -d ozellik-adi
